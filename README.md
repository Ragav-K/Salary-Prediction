# Salary Prediction

Predicts an employee's salary from their profile using machine learning, with a small Flask web app on top.

## Files

| File | Purpose |
|---|---|
| `Salary Data.csv` | Dataset (Age, Gender, Education Level, Job Title, Years of Experience, Salary) |
| `salary_model.py` | Trains and compares models, saves the best one to `salary_model.pkl` |
| `salary_model.pkl` | Saved model (generated by `salary_model.py`) |
| `app.py` | Flask web app for making predictions |

## Setup

Requires Python 3.9+.

```bash
pip install pandas scikit-learn flask joblib
```

## Usage

1. Train the model (skip if `salary_model.pkl` already exists):

   ```bash
   python salary_model.py
   ```

2. Start the web app:

   ```bash
   python app.py
   ```

3. Open http://localhost:5000, fill in the form and click **Predict Salary**.

## Model

Preprocessing: missing values are imputed, categorical columns are one-hot encoded and numeric columns are scaled. The data is split 80/20 for training and testing.

| Model | R² | MAE | RMSE |
|---|---|---|---|
| Linear Regression | 0.852 | 11,597 | 18,821 |
| **Random Forest (best)** | **0.869** | **10,190** | **17,752** |
| Gradient Boosting | 0.865 | 10,774 | 17,980 |

The model with the highest R² on the test set is saved.

## Notes

- The dropdowns in the web app only offer values present in the dataset.
- Predictions are estimates and depend on the quality and size of the training data (about 375 rows).
- `salary_model.pkl` was built with scikit-learn 1.6.1; load it with the same version.
